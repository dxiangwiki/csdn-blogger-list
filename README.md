# CSDN精选活跃博主榜单

博主榜单页面，支持分类筛选，由 GitHub Pages 托管。

🔗 在线访问：[https://dxiangwiki.github.io/csdn-blogger-list/](https://dxiangwiki.github.io/csdn-blogger-list/)

## 文件目录
```
├── index.html      # 主页：博主榜单，支持分类筛选
├── info.html       # 排名参考说明页面
├── blogData.json   # 博主数据
└── README.md       # 项目说明文档
```

## JSON 数据字段说明
| 字段 | 说明 |
| ---- | ---- |
| name | 博主名称 |
| tag | 标签/方向简介 |
| type | 分类标识（筛选用：ai / front / embed / java / cpp / ops / data） |
| desc | 博主简介描述 |
| url | CSDN 个人主页链接 |
